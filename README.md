# SampleOmen

SampleOmen is a real-time data processing engine that leverages auto-scaled clusters as a dynamic orchestrator and scheduler.

With SampleOmen, you get a lightweight tool that stays out of your way.

**What you get**

- SampleOmen is a real-time data
- processing engine that leverages auto-scaled
- clusters as a dynamic orchestrator

## Key Features

- SampleOmen is a real-time data

- clusters as a dynamic orchestrator

## Technology Stack

- rust
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/SampleOmen.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

SampleOmen is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
